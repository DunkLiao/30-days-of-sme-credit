## 檔案用途

每支專案保留：

- `SCRIPT.md`：旁白與每句實測時間。
- `STORYBOARD.md`：六段逐秒分鏡及畫面說明。
- `NOTES.md`：教材依據、案例假設、貼文文案與素材來源。
- `episode.json`：畫面與文案資料。
- `captions.srt`：繁體中文字幕；句內切分按字數估計，逐句起迄來自實際語音長度。
- `index.html`：可編輯的 HyperFrames 合成來源，1080 × 1920。
- `preview.html`：簡易播放器，含播放、暫停與拖曳進度；透過 HTTP 開啟。
- `assets/narration.wav`：本機繁體中文試作旁白。

## 預覽與重製

一般播放器預覽：在專案根目錄執行 `python -m http.server 8080`，開啟
`http://localhost:8080/Video/day05-tax-reconciliation/preview.html`，其餘兩支替換資料夾名稱。

HyperFrames 專業預覽：進入單支專案後執行 `npx hyperframes preview --background`。

內容修改後，在專案根目錄依序執行：

```powershell
python Video/build_trials.py --prepare
powershell -NoProfile -ExecutionPolicy Bypass -File Video/synthesize.ps1
python Video/build_trials.py
```

每支專案使用 `npm run check -- --json` 檢查，以 `npm run render -- --quality high --output renders/video.mp4` 輸出。
