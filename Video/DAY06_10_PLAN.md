# Day 06～10 製作紀錄

日期：2026-11-23。延續已確認的「案例判斷＋圖解」風格，直式 1080 × 1920、24 fps、每支 45～60 秒、繁體字幕、本機合成旁白，無配樂。

## 內容與依據

| 集數 | 核心問題 | 教材依據 | 查核動作 |
|---|---|---|---|
| 06 | 你說查過了，當時依據在哪裡？ | Day06 軌跡留存與送件檢核 | 保存日期、來源、結果及處理紀錄 |
| 07 | 財簽判定只看金額夠嗎？ | Day07 案件性質、計算口徑與適用條件 | 先查適用條件，再列文件要求 |
| 08 | 去年財報還沒出來，資料怎麼接上？ | Day08 財報時點與過渡資料 | 釐清文件期間、查核狀態與補件追蹤 |
| 09 | 有會計師簽名，數字就能直接用嗎？ | Day09 查核意見及形成原因 | 讀意見、原因與影響範圍，補查佐證 |
| 10 | 查到會計師紀錄，就能下結論嗎？ | Day10 資格查證及適任性評估 | 核對身分、內容、日期與期間 |

案例皆為新編教學假設；不把教材中的特定門檻、期限或例外改寫為所有案件通用的現行規則。各集 NOTES.md 記錄課程依據、編輯範圍與正式課程網址。

Day06 將過短的字幕片段與下一段合併，避免一閃而過。Day08 的案例已明確改成「前年正式財報」與「去年尚待查核財報」，同步更新旁白、字幕、畫面及時間軸後重驗與重新輸出。

## 重製

在專案根目錄執行：

```powershell
python Video/build_day06_10.py --prepare
powershell -NoProfile -ExecutionPolicy Bypass -File Video/synthesize.ps1 -Manifest episodes06-10.json
python Video/build_day06_10.py
```

在各集資料夾執行 `npm run check -- --json`，擷取六段中間畫面並檢視後，再回到根目錄執行：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File Video/render_day01_04.ps1 -Manifest episodes06-10.json
python Video/verify_day06_10.py
```

共用輸出腳本雖保留首批檔名，但可透過 Manifest 指定批次，預設行為仍是 Day01～04。既有影片不會由本批建置流程重新輸出。
