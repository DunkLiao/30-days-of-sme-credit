# YouTube 影片自動上傳工具規格

## 目標

為「30 天中小企業授信」影片專案建立一套 Windows 本機命令列工具，透過 YouTube Data API 將完成的影片上傳至指定頻道，並記錄每集的上傳結果，避免漏傳或重複上傳。

## 使用流程

1. 完成影片，並在上傳清單中補上該集資料。
2. 執行命令列工具，檢查待上傳影片及中繼資料。
3. 工具上傳影片，預設設為公開；若設定了未來的排程時間，則依排程發布。
4. 工具顯示上傳結果與 YouTube 網址，並保存紀錄。

## 功能規格

### 1. 上傳清單與共用範本

以 JSON 檔管理各集的上傳資料，並提供可複用的標題與說明共用範本。每集可沿用範本，再補上或覆寫個別內容。

每集資料包含：

- 集數與影片檔案路徑，例如 `Day01.mp4`
- YouTube 標題與說明
- 標籤、分類與語言
- 公開狀態，預設為公開
- 排程發布時間（可選）
- 自訂縮圖路徑（可選）
- 播放清單（可選）

工具上傳前檢查影片檔案、必填欄位、排程時間格式及縮圖檔案是否有效。標題與說明以範本提供初稿，不只依檔名推測內容；逐集資料可自行補充或修改。

### 2. 上傳操作

- 透過 YouTube Data API 上傳影片及中繼資料。
- 以 Google OAuth 授權使用者指定的 YouTube 頻道。
- 支援可續傳上傳，網路中斷後可重試或恢復。
- 支援上傳單集、指定集數／範圍，以及所有待上傳影片。
- 上傳成功後記錄 YouTube 影片 ID、網址、時間與狀態。
- 已成功上傳的集數預設跳過；需明確指定才可重新上傳，避免意外重複建立影片。
- 顯示上傳進度、錯誤原因與可重試狀態。

### 3. 公開與排程發布

- 預設可見度為公開。
- 若指定未來的發布時間，依排程發布；排程影片在發布時間前維持私人狀態。
- 上傳前檢查排程時間必須是有效的未來時間，並清楚顯示使用的時區。
- 工具回報 YouTube 實際接受的可見度及發布狀態。

### 4. 縮圖與播放清單

- 支援逐集指定自訂縮圖並上傳。
- 支援將影片加入指定播放清單。
- 縮圖與播放清單欄位可留空；未指定時不設定該項目。
- 若縮圖或播放清單操作失敗，清楚記錄錯誤，並保留影片上傳結果，讓使用者能單獨重試該步驟。

### 5. 憑證與本機資料

- OAuth 用戶端設定與登入權杖存放於本機，不提交至 Git。
- 將憑證、權杖、暫存檔與執行紀錄加入 Git 忽略規則。
- 影片與憑證不經第三方代管上傳服務。
- 第一次使用時由使用者在本機完成 Google 帳號登入及頻道授權。

## 命令列操作範例（規劃）

```text
youtube-uploader list
youtube-uploader preview --day 01
youtube-uploader upload --day 01
youtube-uploader upload --range 01-05
youtube-uploader upload --all
```

上傳命令開始前先顯示影片、標題、公開狀態、排程時間、縮圖及播放清單摘要，並要求使用者確認；可另外提供明確的 `--yes` 參數供批次自動化使用。

## 不納入第一版

- 自動剪輯、轉檔或修改影片內容
- 自動產生縮圖
- 雲端代管或第三方上傳服務
- 留言、觀看數與頻道分析管理

## 限制與注意事項

YouTube API 上傳需要 Google OAuth 授權及 YouTube Data API 專案設定。API 專案的審核狀態可能影響上傳影片的可見度；工具需回報實際狀態，並在無法依設定公開時提供明確錯誤與後續處理指引。YouTube API 配額、每日上傳限制及帳戶狀態也可能影響上傳結果。

## 驗收條件

- 可讀取共用範本與逐集資料，並正確產生預覽。
- 可依單集、指定範圍或全部待上傳影片執行上傳。
- 預設公開，且能依有效的未來時間排程發布。
- 可設定自訂縮圖與播放清單。
- 成功及失敗狀態會被記錄；已成功上傳的集數不會在一般批次操作中重複上傳。
- OAuth 憑證與權杖不會被 Git 追蹤。
