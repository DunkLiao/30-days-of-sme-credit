# 中小企業徵信與財報分析實務｜使用者操作手冊

這是一套「鎖頭銀行」30 天課程的靜態學習網站。首頁提供課程導覽、學習標記、授信金額判定器、指標速查與三鏈分析案例；Day01 至 Day30 各有獨立課程頁。

## 快速開始

1. 下載或保留整個資料夾，確認 `index.html`、`Day01.html` 至 `Day30.html` 都在同一層。
2. 在檔案總管雙擊 `index.html`，以瀏覽器開啟首頁。
3. 在課程卡片點選標題進入當天頁面；讀完後使用頁腳的「回首頁」。

這種開啟方式不需安裝套件。若要使用 PWA 安裝與離線快取，請透過 HTTPS 網站或 localhost 開啟；直接雙擊檔案時，Service Worker 不會註冊。

## 首頁操作

- **找課程：**點選五大模組標籤，輸入課綱關鍵字，或選擇「僅看尚未完成／已完成」。若找不到內容，使用「重設篩選並顯示全部 30 天」。
- **閱讀摘要：**點選卡片的「查看實務要點」；也可用「全部展開」或「全部收合」。點選卡片標題才會開啟完整的 `DayXX.html`。
- **標記進度：**按各卡片的「標記完成」，首頁上方會顯示已完成天數。按「重設進度」後須再按一次確認；此操作會清除首頁的完成標記。
- **門檻判定：**在「徵信實務速查與判定工作台」輸入聯徵歸戶餘額、本次額度及適用扣除額（單位：萬元），依案件勾選十足擔保、本票保證等條件，查看資料表級別、融資財簽提示與檢核清單。可先點情境按鈕載入範例。
- **指標速查：**用關鍵字與類別標籤篩選財報比率、聯徵代碼、會計師意見及稅務項目。下方「三鏈分析」區提供教學案例與圖表。

判定器是教材輔助工具；實際授信與財報徵提仍應依金融機構內部規章和適用規定辦理。

## 課程頁操作

Day01 至 Day30 均可獨立開啟。各頁通常包含章節展開、已讀進度、搜尋或篩選，部分頁面另有計算情境與自評題；控制項和章節數因課程而異。若要回到課綱，請捲動至頁腳點選「回首頁」。各頁的「重設進度」可能清除該頁的已讀與作答資料，按下前請確認。

## 進度與離線使用

頁面透過 `notebookAppApi` 儲存學習狀態；只有執行環境提供這項介面時，重新開啟才可預期還原進度。一般瀏覽器直接雙擊 HTML 時可以閱讀與操作，但不要依賴完成標記或作答結果作為長期紀錄；目前沒有匯出／匯入進度功能。首頁與各日課程的進度亦非同一份共用紀錄。

在 HTTPS 或 localhost 初次連線開啟網站後，Service Worker 會嘗試預先快取首頁、30 個課程頁及本地 PWA 資源。之後可離線開啟這些頁面；外部字型與 CDN 圖表腳本不在預先快取清單內，相關外觀或圖表可能受離線狀態影響。瀏覽器的「安裝應用程式」是否出現，取決於瀏覽器及其 PWA 支援情況。

## 常見問題

**課程連結打不開？** 確認所有 `DayXX.html` 與 `index.html` 位於同一資料夾，檔名中的日數為兩位數。

**重新開啟後進度不見？** 確認是否在支援 `notebookAppApi` 的環境使用，且沒有切換瀏覽器、網址或清除該環境資料。直接以一般瀏覽器開啟本地檔案不保證持久儲存。

**離線時無法開啟或圖表缺失？** 先在有網路的 HTTPS／localhost 環境完成首次載入；外部資源可能仍需連線。`file://` 網址無法啟用 Service Worker。

## 維護者備註

網站由同層的 31 個 HTML、`favicon.svg`、`manifest.webmanifest` 與 `service-worker.js` 組成。調整課程檔名或離線內容時，請同步更新首頁連結及 Service Worker 快取清單／版本。專案專用維護指引見 [maintain-course-site Skill](.agents/skills/maintain-course-site/SKILL.md)。
